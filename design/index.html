Set it once.

Onboarding is one Screen Time grant and one block to start. The home screen is what's covering right now and what's covering next. Setup is a familiar iOS picker, but with a single design choice the user makes: what should the covered app feel like — a timer, or a friction layer?

02 — The cover screen

The hardest screen
in the app.

When a covered app is opened, Pomoblock takes over the foreground. Two takes here, both OLED-dark and intentionally calm — punishment never beat patience. The user picks one when the block is built.

Take 1
Full pomodoro timer The covered app becomes the timer. 21 minutes left — wait it out, or take an honest break.
Take 2
Breathe, then decide 10s breath, then three honest options: wait, 5-min budget, or end the block.
+ Break
Five honest minutes Light again. Covered apps stay covered during the break — only the timer flips.
03 — iPadOS

The dashboard
you didn't know
you wanted.

iPad gets a sidebar + main split. The same blocks you set up on iPhone, but with room to breathe — the timer ring as a real artefact, the week as a chart, blocks as a glanceable list. Multitasking-aware: covered apps stay covered when split with another app.

04 — macOS

Lives in the menu bar.
Owns the desktop.

A menu bar pop-down for fast control. The cover lives inside the offending app's window — open Slack during Deep Work and Slack itself becomes the timer. ⌃⇧. ends the block on every device at once.

Menu bar pop-down The countdown is also the menu bar icon — see your minutes-left at all times. Quick controls, keyboard shortcuts, syncing status. Two clicks to end the block on all three devices.
The covered window We don't dim or warn the user — we replace the app content with the same dark cover, inside the app's own window chrome. Slack still looks like Slack; it just isn't Slack right now.

Design system — modern minimal · v0.1

Calm, not punitive

The cover is dark, slow, generous. No red, no shake, no shame. The user is the one in control — the timer is just a held breath.

One accent, used twice

A single saturated blue handles the live indicator, the timer ring, and the primary CTA. Everything else is greyscale.

Typography

SF Pro Display for the big numerals at thin weights — feels meditative, not military. SF Pro Text for body. Tabular numerics everywhere counts matter.

Cross-device sync

One block, one timer, three devices. Ending a block on Mac releases iPhone and iPad in the same tick. iCloud-only — Pomoblock has no servers.
